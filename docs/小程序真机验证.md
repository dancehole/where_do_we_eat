## 一、验证前准备（环境配置）

这些不完成，小程序真机跑不起来或接口全失败。

### 1. 接口地址 `API_BASE` 注入（必做）
小程序真机请求必须指向**公网 https 后端**，不能 localhost。
构建时必须通过环境变量注入（已写入 `frontend/config/index.ts` 的 `defineConstants`）：

```bash
cd frontend
API_BASE=https://你的后端域名 npm run build:weapp
```

- [ ] 构建时带上了 `API_BASE=https://…`（https，且已是你的真实后端地址）
- [ ] 未注入时已知 `getApiBase()` 会回退 `localhost:8000`（仅开发者工具关掉 urlCheck 时临时可用，真机不可用）

### 2. 微信公众平台 · request 合法域名（必做）
登录 [微信公众平台](https://mp.weixin.qq.com) → 开发 → 开发管理 → 开发设置 → 「服务器域名」→ request 合法域名，加入：
```
https://你的后端域名
```
否则小程序真机一律网络错误。

- [ ] 后端域名已加入 request 合法域名
- [ ] 后端已配好 HTTPS 证书（微信要求 request 必须是 https）

### 3. 替换 appid（必做）
`frontend/project.config.json` 当前是 `touristappid`（游客态，不能真机预览 / 分享）。

- [ ] 将 `appid` 改为你自己的真实小程序 AppID
- [ ] 微信公众平台「开发管理」里该 AppID 已发布 / 已加入你为开发者

### 4. 定位接口权限（必做）
- [ ] 微信公众平台「开发」→「接口权限」申请开通 **`getLocation`** 接口
- [ ] 小程序 `app.json` 的 `requiredPrivateInfos` 含 `getLocation`（Taro 编译后对应 `permission` 配置）
- [ ] 代码里已声明 `scope.userLocation` 的使用说明（首次调用时弹窗授权）

### 5. 微信 openid 登录（可选）
不配也能用——会优雅回退到「设备匿名身份」（与 Web 端一致）。
要启用微信身份（`app.tsx` 启动 `wx.login` → 后端 `/api/auth/wechat` 走 code2session 拿 openid）：

- [ ] `backend/.env` 已填 `WECHAT_APPID` 与 `WECHAT_SECRET`
- [ ] 后端 `/api/auth/wechat?code=…` 在真机下能返回 openid（开发者工具里 code 是模拟值，可能拿不到真 openid）

## 四、遇到问题时先排查
1. 真机全网络错误 → 先查「一.2 request 合法域名」与后端是否 https。
2. 定位一直失败 / 不弹授权 → 查「一.4 getLocation 权限」与 `scope.userLocation`。
3. 地图空白 → 小程序原生 `<Map>` 需要 `appid` 非游客态（一.3），且组件未被 `if (!IS_H5) return null` 误伤（已修，小程序端走原生分支）。
4. 分享打不开对应碰面 → 确认 `useShareAppMessage` 的 `path` 含 `code`，且后端该碰面仍存在（未被 `end` 并清理）。
